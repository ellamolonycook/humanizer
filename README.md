# Humanizer

Map your AI workforce. Name the agents, give them job descriptions, attach them to the
humans they report to — then find out whether they actually delivered what they promised.

Built for non-technical founders who know they should be delegating to AI, don't know
which agent to build first, and can't tell afterwards whether it worked.

## The loop

1. **What matters to you?** — pick and rank your goals (time back, revenue, capacity, headspace)
2. **Which agents first?** — candidates ranked by expected impact against *your* goals, divided by setup effort, with the reasoning shown
3. **Did it deliver?** — predicted vs actual, per agent, per human, per company
